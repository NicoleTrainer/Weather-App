# Weather App

A browser-based weather app that lets you search any city and view current conditions.

**Live demo:** https://nicoletrainer.github.io/Weather-App/

## Features

- Search weather for any city by name
- Displays current temperature, "feels like" temperature, and a weather icon
- Shows humidity, wind, pressure, and visibility in a stats grid
- Error message shown for invalid or empty searches

## Technologies Used

- **Languages:** HTML, CSS, JavaScript
- **Data:** Weather API (fetched via JavaScript `fetch`)
- **Hosting:** GitHub Pages

## How to Run

1. Clone the repository
2. Open `index.html` in your browser

Or view it live at the link above — no build step or dependencies required.

## Project Structure

- `index.html` — page structure, search bar, and results layout
- `style.css` — styling
- `script.js` — fetches weather data and updates the page

## Notes

This project was built to practice working with a public API and updating the DOM based on fetched data.
